Project Aurora

Overview

Project Aurora is a course-based digital manual management system designed to transition maritime operations from paper-heavy reference materials to an intuitive digital ecosystem. By addressing the challenge of fragmented, hard-to-access documentation, the system delivers central access to critical ship-to-shore operating procedures, elevating compliance, user accessibility, and operational efficiency for maritime personnel.

  • Role: Developer / QA
  • Stack: WAMPP, PHP, Laravel, Composer, Node.js, npm, Git, GitHub

Project Highlights

  • Course-Based Digital Manual System: Built and structured maritime manuals into digitized reference workflows for seamless ship and shore access.
  • Digital Recordkeeping & Archiving: Developed accessible backend and database structures ensuring records remain compliant, traceable, and easily searchable for seafarers.
  • Quality Assurance & Verification: Conducted cross-browser testing, manual content verification, and UI validation to ensure seafarers can accurately retrieve critical guidance under varied operational conditions.
