Appointment Booking System

Overview

This project is an enterprise-grade booking and queuing platform designed to eliminate long waiting lines and physical bottlenecks at service centers. By introducing automated scheduling and real-time visitor routing, the system addresses operational delays, delivering faster visitor processing, enhanced physical security, and structured window allocation.

  • Role: Developer / QA
  • Stack: WAMPP, PHP, Laravel, Composer, Node.js, npm, Git, GitHub

Project Highlights

  • QR Code Verification & Routing: Developed the scanner integration allowing security personnel to scan incoming visitor QR codes and immediately route them to their designated service window.
  • Automated Queueing Workflow: Engineered dynamic queuing logic and counter-staff controls that process visitor status, minimize wait times, and update live queue sequences.
  • Hardware & Integration Testing: Performed end-to-end integration testing between physical QR hardware, live TV display boards, and backend window status controls to prevent race conditions or scan errors.
