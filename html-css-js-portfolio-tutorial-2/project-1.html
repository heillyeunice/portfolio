Transpo Express: Ridesharing Application

Overview

Transpo Express is a digital ridesharing platform created to address urban commuting challenges and streamline transport access for campus and local communities. The application addresses inefficient transport coordination by providing a centralized, accessible digital dispatch and booking environment, significantly reducing travel friction and improving transit visibility.

  • Role: Head Project Leader / 2nd Lead Programmer / QA
  • Stack: React, PHP, Git, GitHub, Replit

Project Highlights

  • Core Rideshare Booking Engine: Developed core functionality enabling users to request rides, coordinate routes, and facilitate travel requests in real time.
  • Leadership & Code Architecture: Led technical direction and core programming responsibilities alongside team management, ensuring continuous integration and smooth delivery.
  • Feature & Flow Validation: Executed functional testing on booking requests, routing logic, and user access permissions to ensure app stability and a seamless user experience.
